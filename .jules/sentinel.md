## 2024-07-25 - [Fix Database Upload Arbitrary File & Information Disclosure]
**Vulnerability:** The script `main/upload_db.php` used insecure permissions (0777 directories, 0666 files), leaked sensitive server path information through `print_r($_FILES)` on failure, and completely lacked file extension validation (allowing arbitrary file upload if not caught downstream).
**Learning:** Legacy debug scripts often contain permissive `chmod` settings and verbose error outputs (like `print_r` or `var_dump`) intended for developers but left exposed in production endpoints.
**Prevention:** Always enforce strict file extension checking (`pathinfo(..., PATHINFO_EXTENSION)` against an allowlist), configure the least permissive file attributes necessary (`0600`/`0700` for application-internal DB files), and route raw exceptions/arrays to `error_log` instead of standard output.
