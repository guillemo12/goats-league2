## 2024-09-15 - [Upload File Information Disclosure and Insecure Permissions]
**Vulnerability:** The database upload script (`main/upload_db.php`) created the target directory and file with overly permissive permissions (`0777` and `0666`), and explicitly dumped the `$_FILES` array to the UI on failure using `print_r($_FILES)`.
**Learning:** Exposing `$_FILES['tmp_name']` to users reveals internal server temporary paths, posing an information disclosure risk. Open file permissions allow potential modification or reading of the application's SQLite database by other processes.
**Prevention:** Always set directory permissions to `0700` and file permissions to `0600` for sensitive application data like SQLite databases. Use `error_log()` for debugging data instead of exposing raw arrays to users.
